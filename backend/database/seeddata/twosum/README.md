# TwoSum

A single-chapter warm-up assessment covering array traversal and hash-map
lookups.

Input:
An array of integers nums and an integer target.

Output:
The indices of the two numbers that add up to the target.

There is exactly one solution, the same element may not be used twice and the
indices may be returned in any order.

Examples:

    nums = [2, 7, 11, 15], target = 9   ->  [0, 1]
    nums = [3, 2, 4],      target = 6   ->  [1, 2]
    nums = [3, 3],         target = 6   ->  [0, 1]
